======================================================================
              테이블 명세서 & 쿼리 가이드 프로그램 (오라클)
                           사용 및 빌드 가이드
======================================================================

본 프로그램은 오라클 데이터베이스의 테이블 명세서 조회, 공통코드 자동 매핑,
그리고 계층형 쿼리 보관함(일괄 가져오기/내보내기) 기능을 지원하는 PyQt6 기반 응용 프로그램입니다.

업무망으로 이관하여 사용하거나 단독 실행 파일(.exe)로 빌드하는 방법을 아래와 같이 안내합니다.

----------------------------------------------------------------------
1. 업무망 이관 시 필요 파일 (2개 세트)
----------------------------------------------------------------------
업무망의 동일한 폴더에 아래의 2개 파일을 함께 복사해 넣으십시오.

  * oracle_guide_app.py : 프로그램 실행 소스 코드
  * metadata.db         : 데이터베이스 파일 (저장한 쿼리, 명세서 데이터 및 설정값 일체)

※ 이전에 불러온 엑셀 명세서 원본 파일들은 이미 데이터베이스(metadata.db)에
   적재되었으므로 업무망으로 가져가지 않아도 무방합니다.

----------------------------------------------------------------------
2. 필수 라이브러리 설치 (실행 전 1회 필요)
----------------------------------------------------------------------
업무망 PC의 CMD(명령 프롬프트) 창을 열고 아래 명령어를 입력하여 필수 패키지를 설치합니다.

   pip install PyQt6 pandas openpyxl pywin32

  * PyQt6    : GUI 렌더링 프레임워크
  * pandas   : 테이블 명세서 데이터 분석 및 가공
  * openpyxl : 엑셀(.xlsx) 파일 읽기 엔진
  * pywin32  : 사내 DRM 엑셀 파일 자동 우회 로드 (선택 사항이나 강력 권장)

----------------------------------------------------------------------
3. 프로그램 바로 실행하기
----------------------------------------------------------------------
필수 패키지가 설치된 상태에서 아래 명령어로 즉시 실행 가능합니다.

   python oracle_guide_app.py

----------------------------------------------------------------------
4. 단독 실행 파일(.exe)로 빌드하기 (배포용)
----------------------------------------------------------------------
사용자에게 소스 코드를 보여주지 않고 더블 클릭으로 바로 실행되는 단독 exe 파일을 만들려면
PyInstaller를 사용하여 빌드하십시오.

  (1) 빌드 도구 설치
      pip install pyinstaller

  (2) 빌드 실행 명령어 (oracle_guide_app.py가 있는 폴더에서 실행)
      pyinstaller --noconsole --onefile --name="테이블명세서" oracle_guide_app.py

  (3) 빌드 완료 후 실행법
      * 빌드가 완료되면 같은 폴더에 'dist' 폴더가 생성되며, 그 안에 '테이블명세서.exe'가 들어있습니다.
      * 생성된 '테이블명세서.exe'를 복사하여 'metadata.db' 파일이 있는 위치로 꺼내놓고 더블클릭하여 실행하시면 됩니다.
      ※ 실행 파일(.exe)과 데이터베이스(.db)는 항상 같은 폴더 내에 함께 있어야 정상 작동합니다.

----------------------------------------------------------------------
[참고] 외부 리소스 파일이 필요 없는 아이콘 내장화
----------------------------------------------------------------------
본 프로그램의 그래픽 아이콘 데이터는 base64 텍스트 형태로 코드(oracle_guide_app.py)
내부에 완전히 포함되어 있습니다. 따라서 별도의 .png 나 .ico 이미지 파일 없이도 
프로그램 실행 및 빌드 시 아이콘이 온전하게 표현됩니다.
