======================================================================
               테이블 명세서 & 쿼리 가이드 프로그램 (오라클 & 업무)
                      업무망(오프라인) 이관 및 설치 가이드
======================================================================

본 문서는 외부 인터넷 연결이 제한된 업무망(오프라인 환경)으로 소스 코드와 
필수 라이브러리 및 자산들을 안전하게 이관하여 설치하고 실행하는 방법을 설명합니다.

----------------------------------------------------------------------
1. 업무망으로 복사해야 하는 파일 및 폴더 목록
----------------------------------------------------------------------
아래의 파일과 폴더들을 업무망의 동일한 위치로 복사하십시오.

  [주요 소스 코드]
  * oracle_guide_app.py  : 오라클 테이블 명세 및 쿼리 가이드 프로그램 소스
  * biz_guide_app.py     : 업무 관리 및 주소록 특화 프로그램 소스

  [자바 기반 한글 내보내기 엔진 폴더 - 필구 복사]
  * hwp_export/          : 고품질 HWP 내보내기 자바 모듈 폴더
    - HwpExporter.class  (컴파일된 자바 파일)
    - hwplib-1.1.9.jar   (한글 라이브러리 JAR)
    - HwpExporter.java   (소스 코드)

  [데이터베이스]
  * metadata.db          : 쿼리 보관함 및 설정 데이터베이스 파일 (데이터 유지용)

  [첨부파일 및 본문 이미지 폴더]
  * attachments/         : 각 업무 글에 연결된 실제 파일 및 본문 붙여넣기 이미지 폴더

  [오프라인 라이브러리 패키지 폴더]
  * whl/                 : 오프라인 설치용 패키지 파일(*.whl) 폴더

----------------------------------------------------------------------
2. 필수 라이브러리 오프라인 설치 (CMD에서 실행)
----------------------------------------------------------------------
업무망 PC의 CMD(명령 프롬프트) 창을 열고, 파일들을 복사한 폴더로 이동한 뒤
아래 명령어를 복사하여 실행하십시오. (파이썬 버전별 휠 파일이 whl/ 폴더에 포함되어 있습니다.)

   pip install --no-index --find-links=./whl pywin32 python-hwpx lxml

  [주요 라이브러리 설명]
  * pywin32     : PC에 설치된 한글 프로그램을 제어하는 COM API 지원 (2순위 엔진용)
  * python-hwpx : 한글 프로그램이 없을 때 HWPX 포맷을 직접 생성해주는 라이브러리 (1순위 엔진용)
  * lxml        : python-hwpx 내부 필수 XML 처리 패키지

----------------------------------------------------------------------
3. [중요] 자바(Java) 실행 환경(JRE/JDK) 확인
----------------------------------------------------------------------
새롭게 도입된 가장 성능이 우수하고 오차가 적은 0순위 HWP 내보내기 방식은
자바 프로그램(HwpExporter)을 내부 서브프로세스로 기동합니다.

따라서 업무망 PC에서 이 기능을 정상적으로 작동시키려면 아래 조건이 만족되어야 합니다.
  1) PC에 자바(JRE 또는 JDK 8 이상)가 설치되어 있어야 합니다.
  2) CMD(명령 프롬프트) 창에서 `java -version`을 입력했을 때 자바 버전이 출력되는 상태여야 합니다.
     (환경변수 PATH에 java 실행 경로가 잡혀있어야 함)

----------------------------------------------------------------------
4. 프로그램 실행
----------------------------------------------------------------------
CMD에서 사용하려는 프로그램에 맞춰 실행합니다.

   [오라클 가이드 프로그램 실행]
   python oracle_guide_app.py

   [업무 가이드 프로그램 실행]
   python biz_guide_app.py

----------------------------------------------------------------------
5. 한글(HWP/HWPX) 내보내기 방식 동작 안내
----------------------------------------------------------------------
프로그램에서 '한글 문서로 내보내기'를 실행하면 아래 우선순위로 자동 작동합니다:

  * 0순위 (자바 엔진 방식 - 최우선 권장): 
    - PC에 Java가 설치되어 있고 `hwp_export/` 폴더가 존재하면 자동으로 작동합니다.
    - 한글 프로그램 설치 여부와 상관없이 오프라인에서 가장 일관되고 정확한 표 간격, 줄바꿈, 이미지 내장을 제공하여 내보냅니다.
  
  * 1순위 (라이브러리 방식): 
    - 0순위 자바 실행이 불가능할 때 `python-hwpx` 라이브러리를 활용하여 HWPX 파일을 생성합니다.

  * 2순위 (COM+ 방식): 
    - PC에 한글 프로그램이 설치되어 있으면 백그라운드로 한글을 실행하여 저장합니다.

  * 3순위 (텍스트 파일): 
    - 위의 모든 방식이 실패할 경우 평문 .txt 파일로 저장됩니다.
