=====================================================================
 전산바이블 / DB돋보기 - 업무망 원클릭 빌드 가이드 (방법 A)
=====================================================================

[빌드 전 준비 사항]
1. Python 및 필수 패키지(PyQt6, pyinstaller 등)가 설치되어 있어야 합니다.
2. 현재 폴더에 아래 파일 및 폴더가 함께 있어야 합니다.
   - oracle_guide_app.py
   - erd_widget.py
   - fonts/ 폴더 (프리텐다드 폰트 4종)

---------------------------------------------------------------------
[원클릭 빌드 명령어]
---------------------------------------------------------------------
업무망 소스 폴더 경로에서 명령 프롬프트(CMD)를 열고,
아래 명령어를 복사하여 실행하세요. (한 줄 전체를 실행)

python -c "import base64, oracle_guide_app; open('app_icon.ico', 'wb').write(base64.b64decode(oracle_guide_app.APP_ICON_BASE64))" && pyinstaller --noconfirm --onefile --windowed --icon app_icon.ico --add-data "fonts;fonts" --collect-data hwpx oracle_guide_app.py


---------------------------------------------------------------------
[명령어 세부 동작 설명]
---------------------------------------------------------------------
1. python -c "import base64..."
   : 외부에서 .ico 파일을 가져오지 않아도, oracle_guide_app.py 내부에
     저장된 고해상도 아이콘 데이터를 읽어 'app_icon.ico' 파일을
     업무망 PC 안에서 즉시 자동 생성(복원)합니다.

2. --icon app_icon.ico
   : 방금 생성된 아이콘을 실행 파일(.exe) 헤더에 직접 삽입하여,
     Windows 탐색기 및 작업표시줄에 전용 아이콘이 표시되도록 합니다.

3. --add-data "fonts;fonts"
   : 프리텐다드(Pretendard) 폰트 파일을 실행 파일 내부에 내장시켜,
     외부 폰트 설치 없이도 UI 글꼴이 선명하고 깔끔하게 렌더링됩니다.

4. --collect-data hwpx
   : 한글(HWPX) 내보내기에 필요한 내부 템플릿 XML 데이터들을 자동으로 수집합니다.

5. --onefile --windowed
   : 콘솔 검은 창 없이, 깔끔한 단일 실행 파일(dist\oracle_guide_app.exe)로 만듭니다.


---------------------------------------------------------------------
[빌드 후 참고 팁]
---------------------------------------------------------------------
* 빌드가 완료되면 'dist' 폴더 안에 'oracle_guide_app.exe' 파일이 생성됩니다.
* 필요에 따라 실행 파일 이름을 '전산바이블.exe' 또는 'DB돋보기.exe'로
  변경하여 사용하시면 됩니다.
* 빌드 직후 탐색기에서 이전 기본 아이콘으로 보일 경우,
  Windows 탐색기의 아이콘 캐시 때문이므로 파일 이름을 바꾸거나
  바탕화면 등 다른 폴더로 복사하시면 전용 아이콘으로 즉시 바뀝니다.
